# Troubleshooting

## The app or panel-menu action is missing

- Rebuild with `npm run build`.
- Recreate the shared container after changing `src/plugin.json` or app provisioning.
- Confirm `digitalrcs-currentviewexporter-app` appears in the shared unsigned-plugin allowlist.
- Confirm the shared compose mount points at this repository's `dist` directory.
- Sign in as `admin` if the anonymous Viewer role does not expose the expected menu interaction.

## Capture says the panel is not materialized

Use **Capture dashboard** to progressively visit materialized dashboard panels. **Capture current panel** still requires the selected panel root to be present in the DOM.

## The final PNG is smaller than the dashboard's measured size

Very tall or wide dashboards are uniformly scaled down to remain within conservative browser canvas limits. The completion message reports the scale percentage when this happens.

## Capture is blank or incomplete

Canvas/WebGL panels can have non-preserved drawing buffers, and cross-origin images can taint canvas export. Grafana 13 panel plugins can supply an alpha screenshot override; the fallback cannot guarantee arbitrary third-party WebGL capture.

## Capture waits even after the spinner disappears

The detector also waits for stable dimensions and DOM/canvas/SVG signatures. Active animation or frequently updating content can keep resetting the stabilization window. The full UI will expose stabilization settings in a later phase.

## A datasource request was observed

First determine whether it was:

- dashboard auto-refresh;
- the initial lazy query for a panel never materialized before;
- a remount-triggered duplicate query;
- a third-party panel's own request.

The Phase 3 test starts counting only after the source panel is fully loaded. Production code does not block legitimate requests.

## Windows install is slow

Scaffold through WSL. If dependency installation under `/mnt/c` stalls or reports rename errors, perform dependency installation with native Windows npm from the project directory. Do not edit `.config`; it is generated by Grafana plugin tools.
