# Support

- Usage and installation questions: [GitHub Discussions](https://github.com/digitalrcs/grafana-current-view-exporter/discussions)
- Reproducible defects: [GitHub Issues](https://github.com/digitalrcs/grafana-current-view-exporter/issues)
- Security concerns: use the private process in [SECURITY.md](SECURITY.md)

Include the Grafana version, plugin version, affected panel type, capture mode, browser, and a minimal reproduction. Do not attach production dashboard exports or query data unless they have been sanitized.
